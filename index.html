About

Most tools complete the line you’re typing. We build the ones that finish the work.

Hinoko Labs is an independent collective based in Japan. No office, no investors, no deadlines set by anyone but us. We are engineers, designers and researchers who build the tools we want to use ourselves — and ship them when they’re genuinely ready.

Right now everything we do orbits one question: what does work look like when software can do the work? Our answer so far is two products — Homu and Kairo — built in the open, side by side.

02

Products

Two tools, one obsession — work that actually gets finished.

Homu

In development

Real-world task agent

Homu takes a task from plain words to a finished deliverable. It drafts the document, builds the deck, runs the research and assembles the report — then hands you something you can actually use. You describe the outcome; Homu does the work.

  • Handles real-world work — docs, decks, research, reports
  • Plans, drafts and refines before it reports back
  • Every deliverable arrives ready to use

Kairo

In development

In-editor coding agent

Kairo works next to you, inside the editor. It completes, refactors and explains code in place, at the speed of thought — while you stay in charge of every commit. Where Homu runs ahead, Kairo keeps pace.

  • Inline completion, refactoring and explanation
  • Lives in your editor — no context switching
  • You own every commit, always
